# Отчёт о мутационном тестировании — ЛР2

## 1. Цель

Оценить способность тестов обнаруживать ошибки в пакетах `internal/domain` и `internal/usecase` с помощью мутационного тестирования.

## 2. Методика

Использован инструмент Gremlins для Go. Проверены четыре пакета:

- `internal/domain/trip`
- `internal/usecase/trip/create`
- `internal/usecase/trip/finish`
- `internal/usecase/trip/get`

Для каждого пакета выполнены исходный и повторный запуски. Результаты сохранены в JSON-файлах каталога `docs/mutation/`.

При повторной проверке использованы параметры `--workers 1 --timeout-coefficient 10` для уменьшения влияния таймаутов.

Всего обнаружено 36 мутаций. Из них 32 обнаружены тестами (`KILLED`), 4 классифицированы как `NOT COVERED`. Выживших мутантов (`LIVED`) нет.

Итоговая эффективность тестов на выполненных мутациях составляет **100%**, а совокупное мутационное покрытие - **88,89%** (32 из 36).

## 4. Анализ результатов

Во всех трёх пакетах `usecase` обнаружены все созданные мутации. Их мутационное покрытие составляет 100%.

В пакете `domain/trip` четыре мутации отмечены как `NOT COVERED`:

- `trip.go:43` - условие проверки пустого UUID пользователя;
- `trip.go:45` - условие проверки пустого UUID водителя;
- `trip.go:47` - изменение условия отрицательной цены;
- `trip.go:47` - изменение граничного условия цены.

При анализе существующего файла `validation_test.go` установлено, что тесты уже содержат проверки пустых UUID, отрицательной цены и допустимости нулевой цены.

Дополнительно выполнена проверка стандартным инструментом Go:

- Общее покрытие операторов пакета `domain/trip`: 97,8%.
- Покрытие операторов функции `New()`: 100%.

Таким образом, классификация четырёх мутаций Gremlins не совпадает с показателем покрытия операторов Go. Точная причина расхождения не установлена. Эти мутации не были выполнены Gremlins, поэтому они не учитываются как обнаруженные тестами.

## 5. Выжившие мутанты и повторная проверка

Выживших мутантов не обнаружено, поэтому добавление тестов специально для их устранения не потребовалось.

Результаты «до» и «после» одинаковы, поскольку существующие тесты уже обнаруживают все мутации, выполненные инструментом. Между запусками тесты и производственный код не изменялись.

Во время одного промежуточного запуска мутация `trip.go:109` получила статус `TIMED OUT`. Повторный запуск с одним рабочим потоком и увеличенным коэффициентом таймаута завершился без таймаутов: 21 `KILLED`, 0 `LIVED`, 4 `NOT COVERED`.

## 6. Вывод

Мутационное тестирование выполнено для всех целевых пакетов. Все 32 выполненные мутации обнаружены существующими тестами, выживших мутантов нет.

Результаты подтверждают эффективность тестов относительно мутационных операторов, применённых Gremlins. При этом четыре непокрытые мутации и ограниченный набор типов мутаций не позволяют считать проверку исчерпывающей.

JSON-отчёты исходных и повторных запусков приложены в каталоге `docs/mutation/`.
